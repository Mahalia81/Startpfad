# Startpfad SRL – SRL in sechs Wochen

Der geführte Einstieg in selbstreguliertes Lernen für Lehrkräfte, allein oder im Team: eine Vorbereitung und sechs Wochen mit Impuls, Auftrag für die Klasse, Checkliste und Selbstreflexion. Dazu Leitfragen für ein wöchentliches Teamtreffen, ein Kollegiumsbarometer, ein Abschlusstreffen mit Entwicklungsplan und ein Rückblick zum Sichern.

Werkzeugkasten zum Startpfad ist die [Strategie-Bibliothek](https://mahalia81.github.io/StrategieBibliothek/). Fragen für Planung, Durchführung und Reflexion stehen im [LernKompass](https://mahalia81.github.io/Lernkompass/).

Grundlage ist der Workshop „Wer lernen kann, lernt mehr – Selbstregulation im Fachunterricht stärken“ von Kristin Schwarz (Dresden 2026).

## Auf den Home-Bildschirm

- **iPhone und iPad:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- **Android:** Seite in Chrome öffnen → Menü → „Zum Startbildschirm hinzufügen“.

Alle Eingaben werden nur im eigenen Browser gespeichert. Es werden keine Daten übertragen. Bitte keine Namen von Schülerinnen und Schülern eintragen.
